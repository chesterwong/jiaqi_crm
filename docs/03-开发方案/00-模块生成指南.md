# CRM模块代码生成指南

> **版本**: v3.0（9模块73张表完整逐表配置）
> **日期**: 2026-05-03
> **策略**: 按模块分批生成，做哪个生成哪个
> **命名风格**: `customers_xxx` 扁平化命名（与 `customers_list` 保持一致）

---

## 一、命名规范（扁平风格）

```
包名:     module_crm（统一）
模块名:   {业务模块前缀}_{表业务名}    → 如 customers_contacts
业务名:   {表业务名}                   → 如 contacts
路径:     backend/plugin/module_crm/{模块名}/
权限:     module_crm:{模块名}:query
```

**说明**：代码生成器不支持两级目录，采用 `customers_xxx` 扁平命名。同一业务模块的表通过模块名前缀归类（如 `customers_` 开头的都是客户管理模块的表）。

**已生成的示例**：
| 表名 | 模块名 | 业务名 | 功能名 |
|------|--------|--------|--------|
| `crm_customers` | `customers_list` | （留空） | 客户档案 |

## 十二、生成后操作清单

### 1. 路由注册（自动发现）

**无需手动修改** `init_app.py`。框架的 `discover.py` 会自动扫描 `app/plugin/module_*/**/controller.py`，发现 `APIRouter` 实例并注册路由。

路由规则：
```
module_crm/customers_contacts/controller.py
→ 容器前缀：/crm                    (module_crm → /crm)
→ 路由前缀：/customers_contacts      (controller中定义的prefix)
→ 最终API：/crm/customers_contacts/...
```

> 重启后端后，在 Swagger 文档即可看到新注册的路由。

### 2. 菜单创建

代码生成器的"写入本地"操作仅生成代码文件，不自动创建菜单。

**方式一（推荐）：在代码生成器页面勾选"生成菜单"**，点击"生成"按钮（非"写入本地"），会自动在 `sys_menu` 表中创建目录 + 菜单 + 按钮三级结构。

**方式二：手动添加菜单**，通过系统管理 → 菜单管理界面添加。

