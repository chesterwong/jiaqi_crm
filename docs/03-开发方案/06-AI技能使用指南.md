```
执行频率: 每天凌晨2点
业务逻辑:
  1. 查询所有成交客户
  2. 计算5维度评分(交易频次/金额/互动频率/满意度/投诉率)
  3. 更新健康度字段
  4. 生成预警记录
```

**输出**:
```python
from apscheduler.schedulers.asyncio import AsyncIOScheduler
from datetime import datetime, timedelta
from app.db.session import AsyncSessionLocal
from app.crud.customer import CustomerCRUD
from app.models.customer_health import CustomerHealth

scheduler = AsyncIOScheduler()

async def calculate_customer_health():
    """计算客户健康度"""
    async with AsyncSessionLocal() as db:
        try:
            # 查询所有成交客户
            customers = await CustomerCRUD.get_deal_customers(db)
            
            health_records = []
            for customer in customers:
                # 计算5维度评分
                score = await calculate_health_score(db, customer)
                
                health_records.append(CustomerHealth(
                    customer_id=customer.id,
                    transaction_frequency=score['transaction_frequency'],
                    transaction_amount=score['transaction_amount'],
                    interaction_frequency=score['interaction_frequency'],
                    satisfaction=score['satisfaction'],
                    complaint_rate=score['complaint_rate'],
                    total_score=score['total_score'],
                    level=score['level'],  # 优秀/良好/一般/风险
                    calculated_at=datetime.now()
                ))
            
            # 批量保存
            await CustomerHealthCRUD.batch_create(db, health_records)
            
            # 生成预警记录
            risk_customers = [h for h in health_records if h.level == '风险']
            if risk_customers:
                await generate_health_alerts(db, risk_customers)
            
            logger.info(f"健康度计算完成,共{len(customers)}个客户")
            
        except Exception as e:
            logger.error(f"健康度计算失败: {e}")
            raise

# 注册定时任务
scheduler.add_job(
    calculate_customer_health,
    trigger='cron',
    hour=2,
    minute=0,
    id='calculate_health_daily',
    name='每日客户健康度计算',
    replace_existing=True
)

# 启动调度器
def start_scheduler():
    scheduler.start()
```

```python
  ws.onclose = () => {
```

## ⚠️ 四、技能使用注意事项

### 4.1 通用规则

1. **尊重框架**: 所有技能生成的代码必须符合FastApiAdmin规范
2. **禁止修改核心文件**: init_app.py, setting.py, vite.config.ts
3. **保持向后兼容**: 新功能不能破坏已有功能
4. **代码规范**: 生成的代码必须通过ruff/black/eslint检查
5. **测试覆盖**: 每个功能必须有对应的测试

---

### 4.2 技能限制

| 技能 | 可以做 | 禁止做 |
|------|--------|--------|
| crm-code-generator | 生成标准CRUD | 修改框架核心代码 |
| crm-database-designer | 设计表结构 | 修改已有表(需创建新迁移) |
| crm-code-reviewer | 检查代码质量 | 自动修复代码(仅报告) |
| crm-test-generator | 生成测试代码 | 跳过测试用例 |
| crm-fullstack-developer | 协调开发 | 修改核心配置文件 |

---

### 4.3 质量保证

**代码生成后必须检查**:
- [ ] 符合FastApiAdmin规范
- [ ] 通过代码规范检查
- [ ] 单元测试覆盖率>80%
- [ ] API接口测试通过
- [ ] 前端页面正常渲染
- [ ] 无控制台错误
