# 自动化开发模板指令

## 一、指令使用说明

### 1.1 指令格式

每个开发任务使用统一的指令模板，包含以下要素：
- **任务标识**: 模块_功能_操作
- **输入参数**: 必要的上下文信息
- **输出要求**: 期望的交付物
- **约束条件**: 必须遵守的规范

### 1.2 指令执行流程

```
接收指令 → 解析参数 → 生成代码 → 自动检查 → 输出结果
```

## 二、模块开发指令集

### 2.1 客户管理模块指令

#### 指令: `CUSTOMER_MODULE_INIT`
**功能**: 初始化客户管理模块完整代码结构

**参数**:
```yaml
module: customer
base_package: com.crm
database: sqlite
tables:
  - crm_customer
  - crm_customer_contact
  - crm_customer_tag
```

**输出**:
- 后端: Entity, Mapper, Service, Controller
- 前端: API, Views, Components, Store
- 文档: 数据库设计, API文档

**执行指令**:
```
初始化客户管理模块，包含客户主表、联系人表、标签表，
使用SQLite数据库，生成完整的CRUD代码和前端页面。
```

---

#### 指令: `CUSTOMER_CRUD_GENERATE`
**功能**: 生成客户管理CRUD代码

**参数**:
```yaml
entity: Customer
fields:
  - name: companyName
    type: String
    required: true
    label: 企业名称
  - name: creditCode
    type: String
    required: false
    label: 统一社会信用代码
  - name: customerLevel
    type: String
    required: true
    label: 客户等级
    enum: [A, B, C]
operations: [CREATE, READ, UPDATE, DELETE, LIST]
```

**输出**:
- Customer.java (Entity)
- CustomerMapper.java (Mapper)
- CustomerService.java (Service接口)
- CustomerServiceImpl.java (Service实现)
- CustomerController.java (Controller)
- CustomerDTO.java (DTO)
- CustomerVO.java (VO)
- CustomerMapper.xml (MyBatis映射)

**执行指令**:
```
为客户实体生成CRUD代码，包含企业名称、信用代码、客户等级字段，
客户等级枚举值为A/B/C，支持增删改查和分页列表查询。
```

---

#### 指令: `CUSTOMER_PAGE_GENERATE`
**功能**: 生成客户管理前端页面

**参数**:
```yaml
page_type: [LIST, FORM, DETAIL]
list_fields:
  - companyName
  - customerLevel
  - contactName
  - phone
  - createdTime
search_fields:
  - companyName
  - customerLevel
form_fields:
  - companyName
  - creditCode
  - customerLevel
  - contacts
```

**输出**:
- CustomerList.vue (列表页)
- CustomerForm.vue (表单页)
- CustomerDetail.vue (详情页)
- customer.ts (API定义)
- customerStore.ts (Pinia Store)

**执行指令**:
```
生成客户管理前端页面，列表显示企业名称、客户等级、联系人、电话、创建时间，
支持按企业名称和客户等级搜索，表单包含企业基本信息和联系人信息。
```

## 三、代码生成指令

### 3.1 后端代码生成指令

#### 指令: `ENTITY_GENERATE`
**功能**: 生成实体类

**模板参数**:
```yaml
table_name: crm_customer
entity_name: Customer
package: com.crm.entity
fields:
  - name: id
    type: Long
    primary: true
    auto_increment: true
  - name: companyName
    type: String
    length: 200
    required: true
    comment: 企业名称
audit_fields: true
soft_delete: true
```

**执行指令**:
```
生成客户实体类，表名crm_customer，包含id、companyName字段，
companyName长度200必填，启用审计字段和软删除。
```

---

#### 指令: `MAPPER_GENERATE`
**功能**: 生成Mapper接口和XML

**模板参数**:
```yaml
entity: Customer
table: crm_customer
package: com.crm.mapper
methods:
  - selectById
  - selectList
  - insert
  - update
  - deleteById
  - selectByCompanyName
```

**执行指令**:
```
为客户实体生成Mapper接口，包含基础CRUD方法和按企业名称查询方法。
```

---

#### 指令: `SERVICE_GENERATE`
**功能**: 生成Service层代码

**模板参数**:
```yaml
entity: Customer
dto: CustomerDTO
vo: CustomerVO
package: com.crm.service
methods:
  - getById
  - getList
  - create
  - update
  - delete
  - importExcel
  - exportExcel
```

**执行指令**:
```
为客户实体生成Service层代码，包含基础CRUD和Excel导入导出功能。
```

---

#### 指令: `CONTROLLER_GENERATE`
**功能**: 生成Controller层代码

**模板参数**:
```yaml
entity: Customer
path: /api/v1/customers
methods:
  - GET /{id}: getById
  - GET /: getList
  - POST /: create
  - PUT /{id}: update
  - DELETE /{id}: delete
  - POST /import: importExcel
  - GET /export: exportExcel
```

**执行指令**:
```
为客户实体生成Controller，接口路径/api/v1/customers，
支持增删改查和Excel导入导出。
```

## 五、测试代码生成指令

#### 指令: `TEST_GENERATE`
**功能**: 生成测试代码

**模板参数**:
```yaml
target: CustomerService
test_type: unit
test_cases:
  - name: testGetById_Success
    description: 根据ID查询客户成功
    setup:
      - mock customerMapper.selectById
    execute:
      - call customerService.getById(1L)
    verify:
      - assert result is not null
      - assert result.companyName equals "测试企业"
  - name: testCreate_Success
    description: 创建客户成功
    setup:
      - prepare CustomerDTO
    execute:
      - call customerService.create(dto)
    verify:
      - assert return value > 0
      - verify customerMapper.insert called
```

**执行指令**:
```
为客户服务生成单元测试，包含根据ID查询和创建客户的测试用例，
使用Mockito模拟Mapper层依赖。
```
