# 开发环境配置指南

## 概述

本文档指导您如何配置CRM系统的开发环境，支持**全自动安装**和**手动安装**两种方式。

## 环境要求

| 组件 | 版本要求 | 用途 |
|------|----------|------|
| JDK | 17+ | 后端运行环境 |
| Maven | 3.9+ | 后端构建工具 |
| Node.js | 20+ | 前端运行环境 |
| Git | 任意版本 | 版本控制、Bash脚本执行 |

## 方式一：全自动安装（推荐）

### 1. 安装 Git for Windows

1. 访问 https://git-scm.com/download/win
2. 下载并安装 Git for Windows
3. 安装过程中保持默认选项即可

### 2. 运行一键启动脚本

```bash
# 在项目根目录双击运行
一键启动.bat
```

此脚本将自动完成以下操作：
1. ✅ 检查环境配置
2. ✅ 编译后端代码（使用阿里云Maven镜像）
3. ✅ 安装前端依赖（使用淘宝npm镜像）
4. ✅ 启动前后端服务
5. ✅ 打开浏览器访问 http://localhost:3000

## 方式二：手动安装

### 步骤1：安装 Java JDK 17

#### 下载地址
- **阿里云镜像**: https://mirrors.aliyun.com/Adoptium/17/jdk/x64/windows/
- **官方地址**: https://adoptium.net/zh-CN/temurin/releases/?version=17

#### 安装步骤
1. 下载 `OpenJDK17U-jdk_x64_windows_hotspot_17.0.9_9.msi`
2. 双击安装，保持默认选项
3. 验证安装：
```bash
java -version
# 应显示: openjdk version "17.0.9" 2023-10-17
```

### 步骤2：安装 Maven 3.9

#### 下载地址
- **阿里云镜像**: https://mirrors.aliyun.com/apache/maven/maven-3/3.9.6/binaries/
- **官方地址**: https://maven.apache.org/download.cgi

#### 安装步骤
1. 下载 `apache-maven-3.9.6-bin.zip`
2. 解压到 `C:\apache-maven-3.9.6`
3. 配置环境变量：
   - 新建系统变量 `MAVEN_HOME` = `C:\apache-maven-3.9.6`
   - 编辑 `Path` 变量，添加 `%MAVEN_HOME%\bin`
4. 验证安装：
```bash
mvn -version
# 应显示: Apache Maven 3.9.6
```

#### 配置阿里云镜像
编辑 `C:\apache-maven-3.9.6\conf\settings.xml`，在 `<mirrors>` 标签内添加：
```xml
<mirror>
  <id>aliyunmaven</id>
  <name>阿里云公共仓库</name>
  <url>https://maven.aliyun.com/repository/public</url>
  <mirrorOf>central</mirrorOf>
</mirror>
```

### 步骤3：安装 Node.js 20

#### 下载地址
- **淘宝镜像**: https://npmmirror.com/mirrors/node/v20.11.1/
- **官方地址**: https://nodejs.org/zh-cn/download/

#### 安装步骤
1. 下载 `node-v20.11.1-x64.msi`
2. 双击安装，保持默认选项
3. 验证安装：
```bash
node --version
# 应显示: v20.11.1

npm --version
# 应显示: 10.x.x
```

#### 配置淘宝镜像
```bash
# 设置npm淘宝镜像
npm config set registry https://registry.npmmirror.com

# 验证配置
npm config get registry
# 应显示: https://registry.npmmirror.com
```

### 步骤4：编译并启动项目

#### 编译后端
```bash
cd crm-server

# 使用Maven Wrapper（推荐，无需单独安装Maven）
mvnw.cmd -s .mvn/settings.xml clean compile

# 或使用系统Maven
mvn -s .mvn/settings.xml clean compile
```

#### 安装前端依赖
```bash
cd crm-web
npm install
```

#### 启动服务

**终端1 - 启动后端：**
```bash
cd crm-server
mvnw.cmd -s .mvn/settings.xml spring-boot:run
```

**终端2 - 启动前端：**
```bash
cd crm-web
npm run dev
```

## 常见问题

### Q1: 提示 "JAVA_HOME not found"
**解决**: 安装JDK 17并配置环境变量，或运行 `scripts/install-all.bat` 自动安装

### Q2: Maven下载依赖速度慢
**解决**: 已配置阿里云镜像，如仍慢可检查网络连接或更换DNS

### Q3: npm install 失败
**解决**: 
1. 检查Node.js版本是否 >= 20
2. 删除 `node_modules` 目录和 `package-lock.json` 后重试
3. 使用淘宝镜像: `npm config set registry https://registry.npmmirror.com`

### Q4: 端口被占用
**解决**: 
- 后端端口8080: 修改 `crm-server/src/main/resources/application.yml` 中的 `server.port`
- 前端端口3000: 修改 `crm-web/vite.config.ts` 中的 `server.port`

### Q5: 数据库连接失败
**解决**: SQLite为嵌入式数据库，无需单独安装。检查用户目录是否有写入权限：
- 数据库路径: `%USERPROFILE%\.crm\data\crm.db`
