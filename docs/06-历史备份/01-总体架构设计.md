# 制造业CRM系统技术实现方案

## 一、项目概述

### 1.1 项目定位
轻量级本地化CRM系统，面向制造业（纸品、彩印、软包装行业），支持：
- ✅ 应用软件本地存储，无需复杂环境部署
- ✅ 局域网内部公司使用
- ✅ 零运维、开箱即用
- ✅ 后期可平滑演进至UniAppX原生应用

### 1.2 核心能力
- 私有本地存储，数据物理隔离
- 单机/局域网双模式运行
- 极简部署（一键启动）
- 模块化架构，易于扩展

## 四、数据库设计

### 4.1 核心表结构

#### 客户管理模块
- `crm_customer` - 客户主表
- `crm_customer_contact` - 联系人表
- `crm_customer_tag` - 客户标签表

#### 跟进管理模块
- `crm_follow_up` - 跟进记录表
- `crm_follow_up_plan` - 跟进计划表

#### 商机管理模块
- `crm_opportunity` - 商机表
- `crm_opportunity_stage_log` - 商机阶段变更日志

#### 产品管理模块
- `crm_product` - 产品表
- `crm_product_category` - 产品分类表
- `crm_product_price` - 产品价格表

#### 系统管理模块
- `sys_user` - 用户表
- `sys_role` - 角色表
- `sys_permission` - 权限表
- `sys_user_role` - 用户角色关联表
- `sys_role_permission` - 角色权限关联表

### 4.2 数据库配置

```yaml
spring:
  datasource:
    url: jdbc:sqlite:${user.home}/.crm/data/crm.db
    driver-class-name: org.sqlite.JDBC
  sql:
    init:
      mode: always
      schema-locations: classpath:db/schema.sql
      data-locations: classpath:db/data.sql
```

```

    ↓ 调用
Service (服务层)
    ↓ 调用
Mapper (数据访问层)
    ↓ 操作

```

## 七、部署方案

### 7.1 开发环境部署

```bash
# 1. 克隆项目
git clone <repository-url>
cd crm-system

# 2. 启动后端
cd crm-server
mvn spring-boot:run

# 3. 启动前端（新终端）
cd crm-web
npm install
npm run dev

# 4. 访问
# 前端: http://localhost:3000
# 后端: http://localhost:8080
```

### 7.2 生产环境部署

```bash
# 1. 构建后端
cd crm-server
mvn clean package -DskipTests

# 2. 构建前端
cd crm-web
npm run build

# 3. 运行
java -jar crm-server/target/crm-server-1.0.0.jar

# 4. 访问 http://localhost:8080
```

### 7.3 桌面端打包

```bash
cd crm-desktop
npm run build:win    # Windows
npm run build:mac    # Mac
npm run build:linux  # Linux
```

## 九、技术风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|---------|
| SQLite并发性能 | 中 | 使用连接池，控制并发数 |
| 大数据量查询 | 中 | 分页查询，索引优化 |
| 局域网访问安全 | 低 | 增加IP白名单，JWT认证 |
| 数据备份 | 中 | 定时备份脚本，一键导出 |
