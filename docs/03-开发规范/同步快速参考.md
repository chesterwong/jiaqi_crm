```bash
# 在项目根目录执行
./scripts/sync-upstream.sh
```

---

## 📋 手动同步步骤

### 1. 准备工作

```bash
cd crm-fastapi

# 检查状态
git status

# 备份
git branch backup-$(date +%Y%m%d)
```

### 2. 获取官方代码

```bash
# 添加 upstream（首次需要）
git remote add upstream https://gitee.com/fastapiadmin/FastapiAdmin.git

# 获取最新
git fetch upstream

# 查看差异
git log HEAD..upstream/master --oneline
```

### 3. 测试合并

```bash
# 创建测试分支
git checkout -b test-sync

# 合并
git merge upstream/master

# 解决冲突（如果有）
git status
# 编辑冲突文件...
git add .
git commit
```

### 4. 测试验证

```bash
# 后端测试
docker-compose up -d
pytest tests/ -v

# 前端测试
cd frontend
npm run test
npm run build
```

### 5. 完成同步

```bash
# 切换回主分支
git checkout master

# 合并测试分支
git merge test-sync

# 推送
git push origin master

# 清理
git branch -d test-sync
```

## ⚠️ 紧急回滚

```bash
# 如果发现问题，立即回滚
git reset --hard backup-YYYYMMDD

# 或者撤销合并
git revert -m 1 <merge-commit-hash>
```

## 🔍 常用命令

```bash
# 查看远程仓库
git remote -v

# 查看分支
git branch -a

# 查看提交历史
git log --oneline -10

# 查看差异
git diff HEAD..upstream/master

# 查看某个文件的变更
git diff HEAD..upstream/master -- path/to/file

# 选择性合并某个 commit
git cherry-pick <commit-hash>
```

## 📊 同步检查清单

同步前：
- [ ] 工作区干净（git status）
- [ ] 已创建备份分支
- [ ] 已通知团队
- [ ] 选择合适的时间

同步中：
- [ ] 仔细检查冲突
- [ ] 重点关注 breaking changes
- [ ] 记录重要变更

同步后：
- [ ] 运行自动化测试
- [ ] 手动测试关键功能
- [ ] 检查错误日志
- [ ] 更新文档
- [ ] 通知团队

## 🆘 常见问题

### 合并冲突太多？
```bash
# 放弃合并
git merge --abort

# 考虑重新基于官方开发
# 或分多次小批量合并
```

### 同步后功能异常？
```bash
# 查看日志
docker logs crm-backend --tail 100

# 定位问题 commit
git bisect start
git bisect bad
git bisect good <known-good-commit>

# 回滚
git reset --hard backup-YYYYMMDD
```

### 只想合并特定的更新？
```bash
# 使用 cherry-pick
git cherry-pick <commit-hash-1>
git cherry-pick <commit-hash-2>
```
