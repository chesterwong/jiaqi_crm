# CRM系统代码生成与自定义界面标注文档

> **版本**: v1.0  
> **日期**: 2026-04-21  
> **目标**: 明确标注哪些模块使用代码生成器，哪些需要自定义界面

---

## 一、总体策略

### 代码生成器适用范围

```
✅ 适合代码生成：
- 标准CRUD（增删改查）
- 列表展示为主
- 表单字段标准
- 无复杂业务逻辑

❌ 不适合代码生成（需自定义）：
- 复杂业务流转（如审批流）
- 多步骤表单
- 可视化图表为主
- 特殊交互需求
- 主从表一体编辑
```

## 五、自定义界面技术选型

### 前端组件库

```
基础组件: Element Plus（已有）
图表组件: ECharts（需安装）
富文本: WangEditor 或 Quill
文件上传: Element Plus Upload
拖拽: VueDraggable
```

### 关键依赖安装

```bash
cd frontend
pnpm add echarts
pnpm add @wangeditor/editor @wangeditor/editor-for-vue
pnpm add vuedraggable@next
```

## 六、总结

### 代码生成 vs 自定义 比例

```
代码生成模块: 14个表
自定义界面: 15个页面

比例: 50% 代码生成 + 50% 自定义

原因:
✅ 标准CRUD用代码生成（快速）
✅ 复杂界面自定义（体验好）
✅ 平衡开发效率与用户体验
```

### 必须自定义的核心界面（TOP5）

```
1. 客户详情页（Tab布局）⭐⭐⭐⭐⭐
2. 商机看板（Kanban）⭐⭐⭐⭐⭐
3. 合同编辑页（富文本+附件）⭐⭐⭐⭐⭐
4. 订单编辑页（主从表一体）⭐⭐⭐⭐⭐
5. 产品编辑页（SKU矩阵）⭐⭐⭐⭐
```

### 开发建议

```
✅ 先代码生成基础模块（1周）
✅ 再自定义核心界面（2周）
✅ 最后自定义辅助界面（2周）
✅ 总工期: 5周

⚠️ 注意：
- 代码生成的代码可以作为自定义的基础
- 自定义界面复用代码生成的API
- 保持UI风格一致
```
