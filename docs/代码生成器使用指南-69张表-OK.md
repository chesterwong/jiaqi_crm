### 二、主从表关系全景图（核心）

#### 1. 客户管理模块主从关系

```
crm_customers（客户主表）⭐
├── crm_contacts（联系人）
│   └── 外键：customer_id → crm_customers.id
│   └── 关系：1个客户 → N个联系人
│
├── crm_customer_addresses（客户地址）
│   └── 外键：customer_id → crm_customers.id
│   └── 关系：1个客户 → N个地址
│
├── crm_customer_pool_logs（客户池日志）
│   └── 外键：customer_id → crm_customers.id
│   └── 关系：1个客户 → N次流转记录
│
├── crm_customer_duplicate_logs（查重日志）
│   └── 外键：customer_a_id, customer_b_id → crm_customers.id
│   └── 关系：N个客户 → N次查重记录
│
├── crm_customer_tags（客户标签关联）
│   └── 外键：customer_id → crm_customers.id
│   └── 关系：1个客户 → N个标签
│
├── crm_customer_timeline（客户动态时间线）
│   └── 外键：customer_id → crm_customers.id
│   └── 关系：1个客户 → N个事件
│
├── crm_customer_health_scores（健康度评分）
│   └── 外键：customer_id → crm_customers.id
│   └── 关系：1个客户 → N次评分快照
│
├── crm_upsell_opportunities（增购机会）
│   └── 外键：customer_id → crm_customers.id
│   └── 关系：1个客户 → N个增购机会
│
├── crm_satisfaction_surveys（满意度调查）
│   └── 外键：customer_id → crm_customers.id
│   └── 关系：1个客户 → N次调查
│
├── crm_intervention_plans（干预计划）
│   └── 外键：customer_id → crm_customers.id
│   └── 关系：1个客户 → N个干预计划
│
└── crm_customer_profiles（客户画像）
    └── 外键：customer_id → crm_customers.id
    └── 关系：1个客户 → 1个画像（1对1）

crm_contacts（联系人表）⭐
└── crm_contact_relations（联系人关系图谱）
    └── 外键：contact_id, related_contact_id → crm_contacts.id
    └── 关系：1个联系人 → N个关系

crm_contacts（联系人表）
└── crm_contact_visits（联系人拜访记录）
    └── 外键：contact_id → crm_contacts.id
    └── 关系：1个联系人 → N次拜访
```

## 第三部分：主从表关系配置规则

### 一、主从表识别规则

#### 规则1: 看外键字段名

```
从表的外键字段命名规律：
crm_contacts.customer_id          → 主表是 crm_customers
crm_opportunities.customer_id     → 主表是 crm_customers
crm_quotation_items.quotation_id  → 主表是 crm_quotations
crm_order_items.order_id          → 主表是 crm_orders
crm_payment_records.plan_id       → 主表是 crm_payment_plans

#### 规则2: 看表名关系

```
主表：名词单数或核心业务实体（customers, opportunities, contracts）
从表：名词复数或带后缀（contacts, items, plans, records, logs）
```

#### 规则3: 看业务逻辑

```
一个客户 → 多个联系人（1对多）

一个报价单 → 多个产品明细（1对多）
一个合同 → 多期付款计划（1对多）
一期付款 → 多次回款记录（1对多）
```

### 二、从表配置关键点

#### 1. 上级菜单必须选择

```
❌ 错误：从表生成为一级菜单
✅ 正确：从表的"上级菜单"选择主表功能

例如：
  联系人管理 → 上级菜单选择"客户管理"
  报价单明细 → 上级菜单选择"报价单管理"
  付款计划 → 上级菜单选择"合同管理"
  回款记录 → 上级菜单选择"合同管理"
```

#### 2. 外键字段配置关联查询

```
❌ 错误：外键字段配置为字典
✅ 正确：外键字段配置为关联表查询

例如：
  customer_id → 关联 crm_customers 表，显示 customer_name
  quotation_id → 关联 crm_quotations 表，显示 quotation_no
  contract_id → 关联 crm_contracts 表，显示 contract_no
```

#### 3. model.py 必须添加 relationship

```python
# ❌ 错误：没有relationship定义
class CrmContactModel(BaseModel):
    customer_id: Mapped[int]

# ✅ 正确：添加relationship
class CrmContactModel(BaseModel):
    customer_id: Mapped[int]
    customer: Mapped["CrmCustomersModel"] = relationship(
        "CrmCustomersModel",
        backref="contacts",
        foreign_keys=[customer_id]
    )
```

#### 4. schema.py 必须添加关联显示字段

```python
# ❌ 错误：只有ID，没有名称
class CrmContactOutSchema(CrmContactBaseSchema):
    customer_id: int

# ✅ 正确：添加关联查询字段
class CrmContactOutSchema(CrmContactBaseSchema):
    customer_id: int
    customer_name: str = None  # 关联查询字段，用于列表显示
```

#### 5. controller.py 必须关联查询

```python
# ❌ 错误：只查从表，不关联主表
async def get_page(...):
    query = select(CrmContactModel)

# ✅ 正确：使用joinedload关联主表
from sqlalchemy.orm import joinedload

async def get_page(...):
    query = select(CrmContactModel).options(
        joinedload(CrmContactModel.customer)
    )
```

### 三、子表配置理解（重要！）

```
⚠️ 重要理解：
"子表表名"和"子表外键列"是主表·模板专用的
用于生成主从表一体的表单（如订单+订单明细）

CRM系统使用的是单表·模板
每个表独立生成，通过菜单层级体现主从关系

正确做法：
主表：不填"子表表名"和"子表外键列"
从表：不填"子表表名"和"子表外键列"
通过"上级菜单"体现主从关系
```

## 第四部分：常见错误及解决方案

### 错误1: 菜单层级错误

**问题**: 从表生成为一级菜单，没有挂在主表下

**原因**: 上级菜单未选择

**解决**:
```
从表配置时：
上级菜单 → 选择对应的主表功能
例如：
  联系人管理 → 上级菜单选择"客户管理"
  报价单明细 → 上级菜单选择"报价单管理"
  付款计划 → 上级菜单选择"合同管理"
```

---

### 错误2: 外键字段显示ID而非名称

**问题**: 列表显示customer_id=1，而不是客户名称

**原因**: 未配置关联查询

**解决**:
```python
# model.py 添加relationship
class CrmContactModel(BaseModel):
    customer: Mapped["CrmCustomersModel"] = relationship(
        "CrmCustomersModel",
        backref="contacts",
        foreign_keys=[customer_id]
    )

# schema.py 添加显示字段
class CrmContactOutSchema(CrmContactBaseSchema):
    customer_name: str = None  # 关联查询字段

# controller.py 修改查询
from sqlalchemy.orm import joinedload

async def get_page(...):
    query = select(CrmContactModel).options(
        joinedload(CrmContactModel.customer)
    )
```

---

### 错误3: 软删除字段重复定义

**问题**: 生成代码报错，deleted_at字段重复

**原因**: 未排除ModelMixin提供的字段

**解决**:
```
检查模板排除列表：
['id', 'uuid', 'status', 'description',
 'created_at', 'updated_at',
 'created_by', 'updated_by',
 'deleted_at', 'version']

如果缺少，手动添加并保存模板
```

### 错误4: 字典未创建

**问题**: 生成代码后，下拉框空白

**原因**: 字典表中没有对应字典

**解决**:
```
1. 访问: 系统管理 → 字典管理
2. 创建字典：
   - crm_industry（客户行业）
   - crm_customer_level（客户等级）
   - crm_customer_status（客户状态）
   - crm_pool_type（资源池类型）
   - ... 所有需要的字典
3. 添加字典数据
4. 刷新页面
```

---

### 错误5: 金额字段精度错误

**问题**: 金额计算出现精度问题（如 10.20 显示为 10.199999999）

**原因**: 使用Float类型而不是Decimal

**解决**:
```python
# ❌ 错误：使用Float
class CrmQuotationItemsModel(BaseModel):
    unit_price: Mapped[float]
    subtotal: Mapped[float]

# ✅ 正确：使用Decimal
from sqlalchemy import Numeric

class CrmQuotationItemsModel(BaseModel):
    unit_price: Mapped[Decimal] = mapped_column(Numeric(18, 2))
    subtotal: Mapped[Decimal] = mapped_column(Numeric(18, 2))
```

---

### 错误6: 物理外键约束导致删除失败

**问题**: 删除客户时报错"违反外键约束"

**原因**: 数据库有物理外键，FastApiAdmin不支持

**解决**:
```sql
-- 删除物理外键
ALTER TABLE crm_contacts DROP CONSTRAINT crm_contacts_customer_id_fkey;
ALTER TABLE crm_opportunities DROP CONSTRAINT crm_opportunities_customer_id_fkey;

-- 用COMMENT注释说明关系
COMMENT ON COLUMN crm_contacts.customer_id IS '客户ID（关联crm_customers.id）';
```
