## 📝 文档维护规范

### 新增文档规则

1. **必须使用数字前缀**: `01-xxx.md`, `02-xxx.md` 等
2. **按重要性排序**: 
   - 01-02: P0核心文档(当前开发必须参考)
   - 03-05: P1重要文档(架构参考)
   - 06-08: P2历史文档(决策记录)
   - 09-10: P3参考文档(偶尔查阅)
3. **命名格式**: `{数字前缀}-{文档主题}.md`
4. **更新现有文档**: 直接修改原文件,不创建新版本

### 文档更新原则

- ✅ **优先更新P0/P1文档**: 核心设计文档保持最新
- ✅ **历史文档不修改**: P2历史文档保留原始决策记录
- ✅ **文档内标注版本**: 在文档头部标注版本号和更新日期
- ❌ **禁止创建重复文档**: 同一主题只保留一个最新文档

### 文档清理规则

- 过时文档移至 `docs/06-历史备份/` 目录
- 临时文档使用后删除
- 图片/HTML文件保持原名称,不加数字前缀
