## 二、一键安装脚本(推荐)

### 2.1 创建一键启动脚本

**文件**: `一键启动.bat`

```bat
@echo off
chcp 65001 >nul
echo ========================================
echo   CRM系统一键启动
echo ========================================
echo.

echo [1/4] 检查Python环境...
python --version >nul 2>&1
if errorlevel 1 (
    echo [错误] 未检测到Python,请先安装Python 3.11+
    echo [下载] https://mirrors.tuna.tsinghua.edu.cn/anaconda/miniconda/
    pause
    exit /b 1
)

echo [2/4] 检查uv包管理器...
uv --version >nul 2>&1
if errorlevel 1 (
    echo [安装] uv包管理器...
    pip install uv -i https://pypi.tuna.tsinghua.edu.cn/simple
)

echo [3/4] 安装后端依赖...
cd crm-backend
uv sync --index-url https://pypi.tuna.tsinghua.edu.cn/simple
cd ..

echo [4/4] 安装前端依赖...
cd crm-web
npm install --registry=https://registry.npmmirror.com
cd ..

echo.
echo ========================================
echo   环境配置完成!正在启动服务...
echo ========================================
echo.

echo [后端] 启动FastAPI服务...
start "CRM后端" cmd /k "cd crm-backend && uv run uvicorn app.main:app --reload --host 0.0.0.0 --port 8000"

timeout /t 3 /nobreak >nul

echo [前端] 启动Vue开发服务器...
start "CRM前端" cmd /k "cd crm-web && npm run dev"

timeout /t 5 /nobreak >nul

echo.
echo ========================================
echo   服务启动完成!
echo   后端: http://localhost:8000
echo   前端: http://localhost:3000
echo   API文档: http://localhost:8000/docs
echo ========================================
echo.

start http://localhost:3000
pause
```

## 三、手动安装(详细步骤)

### 3.1 安装Python 3.11

#### 下载地址(国内镜像)
- **清华镜像**: https://mirrors.tuna.tsinghua.edu.cn/anaconda/miniconda/
- **Python官方**: https://www.python.org/downloads/

#### 安装步骤
1. 下载 `Miniconda3-latest-Windows-x86_64.exe`
2. 双击安装,**勾选"Add to PATH"**
3. 验证安装:
```bash
python --version
# 应显示: Python 3.11.x
```

---

### 3.2 安装uv包管理器

#### 安装命令(使用清华镜像)
```bash
# 使用pip安装uv
pip install uv -i https://pypi.tuna.tsinghua.edu.cn/simple

# 验证安装
uv --version
# 应显示: uv 0.1.x
```

#### 配置uv默认镜像源
**文件**: `~/.config/uv/uv.toml` (Windows: `%APPDATA%\uv\uv.toml`)

```toml
[index]
url = "https://pypi.tuna.tsinghua.edu.cn/simple"
```

---

### 3.3 安装Node.js 20

#### 下载地址(国内镜像)
- **淘宝镜像**: https://npmmirror.com/mirrors/node/v20.11.1/
- **官方地址**: https://nodejs.org/zh-cn/download/

#### 安装步骤
1. 下载 `node-v20.11.1-x64.msi`
2. 双击安装,保持默认选项
3. 验证安装:
```bash
node --version
# 应显示: v20.11.1

npm --version
# 应显示: 10.x.x
```

#### 配置淘宝镜像(强制执行)
```bash
# 设置npm淘宝镜像
npm config set registry https://registry.npmmirror.com

# 验证配置
npm config get registry
# 应显示: https://registry.npmmirror.com
```

**配置文件**: `~/.npmrc`

```ini
registry=https://registry.npmmirror.com
electron_mirror=https://npmmirror.com/mirrors/electron/
sass_binary_site=https://npmmirror.com/mirrors/node-sass/
```

---

### 3.4 安装PostgreSQL 16

#### 下载地址(国内镜像)
- **清华镜像**: https://mirrors.tuna.tsinghua.edu.cn/postgresql/source/v16.2/
- **官方地址**: https://www.postgresql.org/download/windows/

#### 安装步骤
1. 下载 `postgresql-16.2-1-windows-x64.exe`
2. 双击安装,记住设置的密码(如: `postgres123`)
3. 验证安装:
```bash
psql --version
# 应显示: psql (PostgreSQL) 16.2
```

#### 创建数据库
```bash
psql -U postgres

CREATE DATABASE crm_db;
CREATE USER crm_user WITH PASSWORD 'crm_password';
GRANT ALL PRIVILEGES ON DATABASE crm_db TO crm_user;
\q
```

---

### 3.5 安装Redis 7

#### Windows下载
- **微软归档**: https://github.com/microsoftarchive/redis/releases
- 下载 `Redis-x64-3.0.504.msi` (Windows版本最新3.0,生产环境建议用Linux/Docker)

#### Docker方式(推荐)
```bash
docker run -d \
  --name crm-redis \
  -p 6379:6379 \
  redis:7-alpine
```

## 七、常见问题

### Q1: pip/uv下载依赖速度慢
**解决**: 
```bash
# 确认使用清华镜像
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple

# uv配置
uv sync --index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

---

### Q2: npm install 失败
**解决**: 
1. 检查Node.js版本是否 >= 20
2. 删除 `node_modules` 目录和 `package-lock.json` 后重试
3. 确认使用淘宝镜像:
```bash
npm config set registry https://registry.npmmirror.com
npm config get registry
```

---

### Q3: PostgreSQL连接失败
**解决**:
```bash
# 检查PostgreSQL服务状态
# Windows: 服务管理器中查看PostgreSQL服务

# 测试连接
psql -U postgres -h localhost -p 5432

# 检查.env配置
DATABASE_URL=postgresql://crm_user:crm_password@localhost:5432/crm_db
```

---

### Q4: Redis连接失败
**解决**:
```bash
# Windows版本可能未启动
# 使用Docker方式:
docker run -d --name crm-redis -p 6379:6379 redis:7-alpine

# 测试连接
redis-cli ping
# 应返回: PONG
```

---

### Q5: 端口被占用
**解决**: 
- 后端端口8000: 修改启动命令 `--port 8001`
- 前端端口3000: 修改 `crm-web/vite.config.ts` 中的 `server.port`
- PostgreSQL端口5432: 修改 `postgresql.conf` 中的 `port`
- Redis端口6379: 修改 `redis.conf` 中的 `port`

---

### Q6: Docker拉取镜像慢
**解决**:
```bash
# 配置Docker国内镜像源
# 文件: ~/.docker/daemon.json
{
  "registry-mirrors": [
    "https://registry.cn-hangzhou.aliyuncs.com",
    "https://registry.docker-cn.com"
  ]
}

# 重启Docker Desktop
```

## 八、环境检查脚本

**文件**: `scripts/05-安装部署/01-环境检查.sh`

```bash
#!/bin/bash

echo "========================================"
echo "  CRM开发环境检查"
echo "========================================"

# 检查Python
echo "[1/6] 检查Python..."
if command -v python &> /dev/null; then
    PYTHON_VERSION=$(python --version 2>&1)
    echo "✅ $PYTHON_VERSION"
else
    echo "❌ 未安装Python,请安装Python 3.11+"
    echo "   下载: https://mirrors.tuna.tsinghua.edu.cn/anaconda/miniconda/"
fi

# 检查uv
echo "[2/6] 检查uv..."
if command -v uv &> /dev/null; then
    UV_VERSION=$(uv --version 2>&1)
    echo "✅ $UV_VERSION"
else
    echo "❌ 未安装uv"
    echo "   安装: pip install uv -i https://pypi.tuna.tsinghua.edu.cn/simple"
fi

# 检查Node.js
echo "[3/6] 检查Node.js..."
if command -v node &> /dev/null; then
    NODE_VERSION=$(node --version 2>&1)
    echo "✅ $NODE_VERSION"
else
    echo "❌ 未安装Node.js,请安装Node.js 20+"
    echo "   下载: https://npmmirror.com/mirrors/node/v20.11.1/"
fi

# 检查npm镜像
echo "[4/6] 检查npm镜像配置..."
NPM_REGISTRY=$(npm config get registry 2>&1)
if [[ "$NPM_REGISTRY" == *"npmmirror.com"* ]]; then
    echo "✅ npm镜像: $NPM_REGISTRY"
else
    echo "⚠️  npm未使用淘宝镜像,建议设置:"
    echo "   npm config set registry https://registry.npmmirror.com"
fi

# 检查PostgreSQL
echo "[5/6] 检查PostgreSQL..."
if command -v psql &> /dev/null; then
    PSQL_VERSION=$(psql --version 2>&1)
    echo "✅ $PSQL_VERSION"
else
    echo "❌ 未安装PostgreSQL"
    echo "   下载: https://mirrors.tuna.tsinghua.edu.cn/postgresql/source/v16.2/"
fi

# 检查Redis
echo "[6/6] 检查Redis..."
if command -v redis-cli &> /dev/null; then
    REDIS_PING=$(redis-cli ping 2>&1)
    if [[ "$REDIS_PING" == "PONG" ]]; then
        echo "✅ Redis运行正常"
    else
        echo "⚠️  Redis未运行"
    fi
else
    echo "❌ 未安装Redis"
    echo "   Docker: docker run -d --name crm-redis -p 6379:6379 redis:7-alpine"
fi

echo ""
echo "========================================"
echo "  环境检查完成!"
echo "========================================"
```

## 十、强制规则

### 🚨 必须遵守

1. ✅ **Python依赖** - 必须使用清华镜像,禁止直接访问pypi.org
2. ✅ **Node.js依赖** - 必须使用淘宝镜像,禁止直接访问registry.npmjs.org
3. ✅ **Docker镜像** - 必须使用阿里云/腾讯云镜像,禁止直接访问docker.io
4. ✅ **系统安装** - 优先使用国内镜像下载,禁止访问国外官网
5. ✅ **CI/CD** - 所有构建脚本必须配置国内镜像源

### ❌ 禁止行为

1. ❌ 直接 `pip install` 不指定镜像
2. ❌ 直接 `npm install` 不配置淘宝镜像
3. ❌ 直接 `docker pull` 不配置镜像源
4. ❌ 在代码中硬编码国外URL

### ⚠️ 违规后果

- 下载超时/失败
- 构建失败
- 警告bug频发
- 开发效率降低80%
